User intent

Important requests and constraints are saved as passive data, never silently converted into tasks.

Session capsules

Before compaction or exit, djobs groups the goal, progress, failures, and next step into a compact local capsule.

Relevant recall

The current request searches older repository memory, so a useful constraint can rank above newer unrelated activity.

Memory controls

Inspect, search, forget one item, opt out per prompt, or clear passive memory for the current repository.
