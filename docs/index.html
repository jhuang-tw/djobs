Passive context, explicit ownership.

Zero-touch memory

The first MCP tool call creates local memory and installs the detected host adapter automatically. No per-project setup command is required.

Explicit handoff

checkpoint() deliberately claims work, while handoff() explicitly releases or completes it with bounded evidence.

Four compact tools

sync_workspace, checkpoint, handoff, and resume_delta keep ordinary agent context small.

Local compatibility

Copilot is the default local host, with optional adapters for Codex, Claude Code, Gemini CLI, Kimi Code, and custom agents.

Local by default, conservative by design.

State stays in SQLite on the user's machine. Adapters fail open, unrelated settings are preserved, observations are treated as untrusted data, and no cloud account or remote queue is required.

One repository identity across local shells.

Git roots, Windows paths, WSL mounts, and common Git Bash spellings resolve to compatible local identities, so agents can continue the same work without duplicating ownership.
